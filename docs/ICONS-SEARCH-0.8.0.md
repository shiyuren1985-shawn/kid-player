# 0.8.0 桌面图标和投稿搜索

日期：2026-09-08。版本 0.8.0 / code 16。

## 用户功能

“播放设置 → 选择桌面图标”提供 8 款：原有萌可、原创 Kid Player、奥特曼、擎天柱、美少女战士、哆啦 A 梦、原创太空小熊和小恐龙。点击图案预览选中状态，再点击“使用这个图标”应用。更换系统桌面启动图标，并同步应用内标题图标，名称保持 kid player。部分桌面刷新图标需要短暂等待。

搜索栏放在 UP 主列表页面顶部、应用标题下方，输入框保持固定；下方选择“当前 UP 主”或“全部订阅”。输入后自动筛选标题，键盘“搜索”可收起键盘；清除关键词恢复普通列表并收起键盘。搜索支持中英文、大小写/全半角归一及多个空格分隔关键词（均需匹配）。结果不限制为 30 个，原来的 30 条限制只属于观看历史。

搜索只读取启用 UP 主的已缓存投稿，不向 B 站实时提交搜索请求。未完成目录加载的作者会计数提示，新增投稿在目录刷新后可搜索；“刷新当前 UP”沿用已有同步冷却，不在全部搜索时自动并发抓取所有作者。结果显示原作者并使用其 UID 路由播放、收藏与历史，当前作者选择不被搜索结果点击修改。停用作者不出现在结果中。

## 实现与边界

使用 Android [activity-alias](https://developer.android.com/guide/topics/manifest/activity-alias-element) 及 [PackageManager 组件启用接口](https://developer.android.com/reference/android/content/pm/PackageManager#setComponentEnabledSettings(java.util.List))。MainActivity 始终启用，8 个别名名字保留供后续升级兼容。Android 13+ 批量切换状态；较早系统先启用新别名，再禁用其余。选择保存在原应用偏好中，启动时检查入口一致性。没有修改包名或签名，不生成额外桌面快捷方式。

搜索在独立线程执行，输入防抖 180 ms，过期任务取消/结果作废；目录更新、作者启停时重新计算。查询及范围保留于 Activity 保存状态，输入框不会因列表刷新重建。跨作者元信息保存使用明确作者 scope，播放器沿用现有作者与 BV 校验。

测试包装脚本新增 launcher 组件状态备份/恢复；这是 PackageManager 状态，不能只备份 SharedPreferences。Android 12 shell 不允许把组件恢复为 DEFAULT，故使用受专用 AVD 限制的 LauncherStateRestoreTest 在应用 UID 下恢复，再验证 dumpsys 状态与偏好。此测试辅助代码不进入产品 APK。
