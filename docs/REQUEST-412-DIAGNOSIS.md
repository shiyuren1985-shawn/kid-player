# 投稿接口 412 对照诊断

日期：2026-09-07；产品 0.7.0 / 11；目标 UID 3546918961547843。

## 实际结果

专用 KidCinema_Tablet_12 模拟器，Android 12；Chrome 91.0.4472.114。模拟器系统 http_proxy 为 null，但没有核对宿主网络出口及其与家庭平板是否一致。未使用账号凭据或更换网络出口。

每次网络请求完成后至少等待 10 秒，每组投稿只读取第 1 页。共 4 次 nav、4 次投稿请求和 1 次首页请求；没有批量分页或自动重试。nav 均 HTTP 200。

| 对照条件 | 投稿结果 |
|---|---|
| 原始请求，降低频率 | HTTP 412 |
| 使用模拟器实际 WebView User-Agent | HTTP 412 |
| 再添加空间页 Referer 和 Origin | HTTP 200，但 JSON code=-352，未获取投稿 |
| 启用匿名 Cookie 容器并尝试访问首页 | 首页 HTTP 302，未跟随跳转，未取得 Cookie；投稿仍 HTTP 412。不能算作有效 Cookie 会话实验 |

浏览器对照：同一模拟器 Chrome 首次启动，关闭统计上报，跳过账号同步。打开用户提供的官方空间 URL，最终到达 m.bilibili.com/space/3546918961547843。无登录操作，UI 自动化文字树包含正确的 UP 名、资料以及多条视频标题。此处没有执行图片视觉检查；文字树包含屏幕外节点，不能据此宣称所有视频均可见、全部投稿已加载或播放通过。没有证据证明移动网页使用同一个 WBI 投稿 API。

## 可得结论及边界

- 当前原生请求方式的受限可复现；仅放慢到 10 秒或更换真实 WebView UA 未解决。不能认定 200 毫秒分页是唯一原因。
- HTTP 200 与业务成功分开验证，-352 仍是失败。
- 同一模拟器能打开官方移动页面，说明并非这台设备无法访问整个 B 站；网页可用不等于特定 API 可用。
- 无法确认具体服务器风控规则、封禁周期、是否针对所有第三方客户端；顺序小样本不能把返回码变化严格归因于某个请求头。
- 有效匿名会话、用户登录会话、现代浏览器版本对照、真实平板请求日志与全目录联网验收仍未测试。未声称修复。
