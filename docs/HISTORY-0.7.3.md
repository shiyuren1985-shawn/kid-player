# 0.7.3 图片缓存与观看历史

日期：2026-09-07。版本 0.7.3 / versionCode 14。

## 行为

- RemoteImages 的共享图片磁盘缓存从 24,000,000 调整为 200,000,000 字节（200 MB），不预分配；沿用 URL 缓存键和最近使用淘汰方式。内存图片缓存仍为 12 MiB，视频片段缓存仍为 256 MiB。
- 导航“继续观看”改为“观看历史”。沿用当前 UP 主／视频来源的范围，每个范围保留最近观看的 30 个不同视频，按最近观看时间倒序排列；重复观看更新位置，完成播放也留在历史中。
- 实际首帧呈现时记录，后续进度保存更新最近观看时间。仅点击从头播放或播放前失败不凭空建立历史。
- 使用原有 watched 时间戳兼容已存记录；首次读取会收敛到 30 条。播放进度为 0 不再作为排除条件。
- 保存播放过的视频元信息，允许历史条目展示已缓存标题和封面；在线播放仍检查当前启用作者与当前目录，已被移除的投稿不会绕过播放检查。
- “清空观看历史”只删除当前范围的观看时间戳，确认框可以取消；保留收藏、视频目录和断点进度。清空后重新实际播放会再次记录。
