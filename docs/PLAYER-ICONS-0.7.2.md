# 0.7.2 播放操作图标与使用说明

日期：2026-09-07。用户已反馈 0.7.1 在家庭平板可打开；此反馈不扩写成长时间播放或所有作者已验收。

## UI 修改

播放页四个操作使用 40dp Android 矢量图标及文字，点击区域最小高度从 72dp 增至 112dp：返回箭头/蓝底、暂停或播放/绿底、空心或实心爱心/粉底、退出门/橙底。文字、形状和底色共同表达含义，保留原无障碍描述、遥控焦点描边和触摸反馈。播放结束时常驻播放操作切换为重放图标。没有改变直接 B 站、SMB、续播或关闭行为。

## 图片缓存 24 MB 的含义

24,000,000 字节是全应用所有 UP 主头像/封面共用的磁盘缓存上限，保存下载后的压缩图片文件，不是每张图、每个 UP 的配额，也不是视频容量。读过的缓存更新最近使用时间，超过上限后删除较久未使用的图片；再次需要时重新下载。淘汰图片不会删除投稿目录、收藏或观看进度。

24 MB 是原型阶段为控制存储占用选择的保守默认值，并非平台规定，也未依据家庭平板全部 UP 的封面规模测算为最优。若每张图平均 100 KB，粗算约能保存 240 张；这只是示例，不是实际封面统计。多作者、大目录来回浏览确实可能频繁淘汰，今后适合提供更大的可配置磁盘容量。当前内存图片缓存 12 MiB 和视频片段缓存 256 MiB 为不同层次，不能把磁盘图片上限理解成内存解码上限。本次只修改用户明确提出的播放图标，未变更容量。

## 继续观看的实际逻辑

在线模式从当前 UP 主现有目录筛出保存进度大于 0 的视频；切换 UP 后查看对应作者，当前不按最近观看时间重新排序。点进去从保存的位置继续；播放器每 2 秒保存进度，退出时也保存。真正播放到结尾时将进度置 0，因此从继续观看中移除。它是未完成观看的续播列表，不是包括看完视频在内的完整观看历史。已从当前目录移除的投稿不会继续列在这里。
