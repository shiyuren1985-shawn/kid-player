## 实际 UID 诊断

UID 3546918961547843 的作者接口识别为“混子哥边画边讲”，公开合集接口 code=0、total=0、seasons_list=[]、series_list=[]。旧 0.6.1 在 AVD 中因此记录 UPDATED、0 条视频、错误为空；立即刷新返回 COOLDOWN。这复现了用户的空目录和“刚刚检查过”。

## 最终实现

- BiliCatalog 读取全部投稿分页；主目录与合集分类分离。没有原来每作者 30 条、500 条扫描或 20 个合集的总量截断。
- 逐页检查 UID、分页大小、总数和重复项，逐页持久化。中断时保留旧条目并标记未完成；全部分页确认后才删除已不在新完整快照中的旧条目。
- 合集与系列目录、内容均分页；可返回全部投稿，推荐卡跟随合集筛选。合集失败独立显示，不隐藏投稿。
- 首页重复管理入口删除，统一到播放设置；冷却给出剩余秒数和失败原因。
- 图片按 URL 复用，磁盘/内存有上限，内存压力可释放。作者资料刷新成功后采用新头像 URL。
- Media3 单例按需片段缓存，256 MiB LRU；空间不足时不建立新缓存；不同签名 URL 不混用字节。设置可清理图片/视频缓存，不删除名单、目录、收藏或进度。
- 缓存依据及已采用范围：[缓存策略与官方资料](CACHE-PRACTICES.md)。
